# Talentri

Le plastique qui révèle les talents. Talentri collecte le plastique des stades et des quartiers avec les ASC, le transforme à Thiès et le rend sous forme d'équipements sportifs.

Site : https://tahiboutall.github.io/Talentri/

Projet présenté au Sport for Change Challenge (Dakar 2026). Les objets du catalogue sont des modélisations 3D de concept, et le tableau de bord affiche des données de démonstration.
